{%- comment -%} Obfuscated email link. Without JavaScript it reads "user [at] domain [dot] tld" and is not a link; assets/js/main.js turns it into a mailto: link and, if `label` is given, shows the label instead. Usage: {% include email.html class="pill" label="Email" icon=true %} {%- endcomment -%} {%- assign e = site.data.profile.email -%} {% if include.icon %}{% include icon.html name="mail" %}{% endif %}{{ e.user }} [at] {{ e.domain | replace: ".", " [dot] " }}
